React 19 错误监控：接入与验证

点击「React 组件异常」可看到 ErrorBoundary 的降级界面和异常报告。ErrorBoundary 捕获子树渲染异常；普通 Fetch/XHR 由浏览器 SDK 独立采集。

npm install @mitojs/browser@4.0.0 @mitojs/react@4.0.0
import { init } from '@mitojs/browser'
import { ErrorBoundary, MitoProvider } from '@mitojs/react'

const MitoInstance = init({ dsn: '/reports' })

// 在渲染入口包裹要保护的子树：
<MitoProvider MitoInstance={MitoInstance}>
  <ErrorBoundary fallback={<p>此组件暂时不可用</p>}><App /></ErrorBoundary>
</MitoProvider>

/reports 是示例接收地址，接入项目时请替换为自己的监控接收端。本 Demo 的请求和上报在浏览器本地拦截，观察窗展示 SDK 实际生成的报告。
